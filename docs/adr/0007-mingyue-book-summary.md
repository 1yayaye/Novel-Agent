# ADR-0007：以完整明月流程实现全书剧情提取

状态：已采纳。

旧流程以简化的片段、阶段和全书总结协议配合压缩滚动状态，不能保留明月专项资料的栏目和累积细节。作者需要明月的完整整理流程，并要求本次只实现后端、留出前端接口。

## 决策

- `book_summary` 只处理整本导入正文。默认 50,000 字符分段、300,000 字符触发阶段，短章合并、长章按段落或句末拆分；模型预算可缩小片段。
- 保留明月 13 类完整提示词及执行依赖，每片段完成小总结和主线更新，每阶段完成大总结及八类专项资料，首阶段额外判断体系，最终生成超级总结和事实型大纲候选。
- 使用现有任务和步骤检查点持久化每个产物；遇错停止，恢复复用已提交步骤，不提供跳过或旧结果降级。沿用现有模型网关的网络重试与 JSON 格式修复。
- 全文处理且完整传递累积资料，不采样、截断或分层压缩。预算不足明确失败。
- 冻结来源顺序、标题、版本、正文哈希及提示词/连接预算；来源变化后拒绝续跑、发布和应用，允许查看、复制、导出。
- 本流程不写章节摘要、知识建议或一致性问题。已有独立分析工具保留各自职责。
- 自动创建缺失的大纲草稿；已有大纲通过比较和版本校验后明确应用，不自动覆盖。梗概、大纲初次发布和任务完成采用同一事务。
- 不迁移旧检查点，不增加通用工作流编辑器，不开放单步骤提示词编辑，也不支持编辑账本后续跑。

## 影响

模型调用次数和累积输入量增加，以保留原流程细节。长书可能需要更大上下文和输出预算；超过预算会停止。完整模型效果需要另行验收，不能仅由流程对齐或步骤通过推定。前端接入约定见 `docs/book-summary-api.md`。
